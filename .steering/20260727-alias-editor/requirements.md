# 要求内容 — U9 alias-editor（別名チップ編集UI）

## 概要

検索結果の行から、その場でブックマークに複数の別名（エイリアス）をチップUIで追加・削除・再編集できるようにする。ALIAS_EDIT モード（U8 モード状態機械）と連携し、正規化重複の自動排除・上限（20個/50文字）・マッチ別名の先頭ハイライトを備える。

## 背景

Findmark の中核価値「自分だけの別名で数秒で引ける検索」を成立させるには、別名を**その場で**登録・編集できる導線が必要（PRD 機能3）。データレイヤーの `AliasStore`（U5）と検索エンジン（U6）は完成済みで、モード状態機械（U8）も整備済み。本単位は、これらを結ぶ **UI 実体（AliasEditor）** を実装し、デザイン状態 **1e（別名編集中・チップ入力）** を再現する。

## 実装対象の機能

### 1. 別名チップ編集UI（AliasEditor）
- 結果行の 2 段目をチップ入力ボックス（状態1e）に差し替え、既存別名を `✕` 付きチップで表示する。
- テキスト入力後、**Enter / `,` / Space** で入力中テキストをチップとして確定する。
- 入力欄が空のときの **Backspace** で直前のチップを削除する。
- チップの **`✕`** で個別削除、**チップクリック**でそのチップを入力欄に戻して再編集する。
- マッチした別名（`matchedAliases`）を**先頭**に寄せ、accent 塗りでハイライトする（省略せず全表示）。
- 別名の追加/削除は即時に `AliasStore.upsert(url, aliases)` へ永続化する（楽観更新→失敗でロールバック）。
- 上限表示（`n / 20`）とヒント文（「Enter で確定 / Backspace で直前のチップを削除」）を表示する。

### 2. ALIAS_EDIT モード連携と入口
- LIST モードで選択中の行に対し、**Ctrl/Cmd+;**（`resolveShortcutIntent`）または**別名エリアのクリック**で ALIAS_EDIT に入る。
- **Escape** で ALIAS_EDIT を終了し LIST に戻る（`exitToList`）。
- 編集対象が結果から消えた場合は自動で LIST に戻す。
- IME 変換中（`isComposing`）の Enter/Space は確定に使わない（日本語別名の変換確定を誤ってチップ化しない）。

### 3. 検索索引への即時反映
- 別名編集の結果を検索索引（`SearchEngine`）へ即時反映し、編集直後の結果行の別名チップ表示が最新になるようにする（再読み込みなし）。

## 受け入れ条件

（出典: mvp-development-flow U9「受け入れ基準」＋ PRD 機能3 受け入れ条件）

### 別名チップ編集UI
- [ ] 1件のブックマークに複数の別名をチップで登録できる（PRD 機能3）
- [ ] 入力後 Enter / `,` / Space でチップ確定、空入力時の Backspace で直前チップ削除、チップ `✕` で削除、チップクリックで再編集ができる（PRD 機能3）
- [ ] 正規化後に比較して重複を自動で弾き、弾いた際は既存の該当チップを一瞬光らせる（PRD 機能3 / UC-2 の「既存チップを一瞬光らせる」）
- [ ] 1件あたり最大20個・1個あたり最大50文字の上限を課す（超過時は追加不可・上限表示）（PRD 機能3 / U5 の上限）
- [ ] 検索でマッチした別名は先頭にハイライト付きで必ず表示する（省略対象から除外）（PRD 機能3）

### ALIAS_EDIT モード連携
- [ ] 選択行で Ctrl/Cmd+; または別名エリアのクリックで別名編集に入れる（design 1e / Interactions）
- [ ] Escape で編集を終了し LIST に戻る（functional-design ALIAS_EDIT 行）
- [ ] IME 変換確定の Enter/Space をチップ確定に使わない（日本語別名を正しく登録できる）

## 成功指標

- 別名 upsert が体感即時（100ms 以内、PRD 非機能）で反映される。
- 別名編集の中核ロジック（確定/重複判定/上限/削除/並び）が純粋関数として単体テストで担保される（shared/storage/pure-model 80% 目標方針）。

## スコープ外

以下はこのフェーズでは実装しません:

- 未ヒット時の「別名を付けて探しやすくする」登録提案（Post-MVP・機能設計「結果0件」導線）
- ローマ字→かな自動変換・漢字読み推定（辞書同梱、Post-MVP）
- インライン編集（リネーム/URL編集）と削除/アンドゥ（U10 の担当。1d は別単位）
- 別名編集中の候補サジェスト（`alias:candidate-up/down` の UI 化は将来単位）
- 現在ページ登録パネルからの別名編集（U14）
