# 要求内容 — U7 popup-search-shell（デザイン状態1a準拠）

## 概要

検索ポップアップの表示基盤を、`docs/design/` の**デザイン状態1a（通常状態）**に忠実な **760×560 の3領域シェル**として実装する。ボイラープレートのデモ Popup を置換し、起動即フォーカス・インクリメンタル検索・キーボード/クリックでブックマークを開く導線、ファビコン表示（取得失敗時は頭文字アバター）、および**デザイントークン定義とフォント同梱**を提供する。（PRD 機能1・機能10、[docs/mvp-development-flow.md](../../docs/mvp-development-flow.md) U7 /「デザイン準拠」、[docs/design/README.md](../../docs/design/README.md)）

## 背景

U1〜U6 でドメイン/データレイヤー（Normalizer/BookmarkService/AliasStore/SearchEngine）が UI なしで揃った。U7 はこれらを初めて UI から結線し、Findmark の基本導線（起動→検索→開く）を成立させる**フェーズ2 の入口**。あわせて、`docs/design/` を**レイアウトの正**として、以降の編集・整理機能（U8〜U14）が乗る **3領域シェル（PopupShell / SearchHeader / FolderTree / ResultList）** とデザイントークン・フォント基盤をここで確立する。

## 実装対象の機能

### 1. デザイン状態1aの3領域シェル（PRD 機能1 / docs/design 1a）
- **PopupShell**: 760×560 固定・角丸12・影・`overflow:hidden`。ヘッダー56 + ボディ（左ペイン220 + 右ペイン flex:1）。
- **SearchHeader**: 検索ボックス（h34・虫眼鏡アイコン・プレースホルダ「ブックマークを検索...」・フォーカスリング）と「＋追加」ボタン（プレースホルダ表示。登録機能は U14）。
- **左ペイン FolderTree（表示＋基本の選択絞り込み）**: ブックマークツリーからフォルダを描画（「すべて」+ 各フォルダ・インデントガイド・開閉三角）。「三角＋📁＋名前」の押下で開閉。**フォルダ名の右の選択チップ**（件数表示に代替・コンパクトなラジオ風トグル18px・選択中は accent＋チェック）を押すとそのフォルダ配下（サブフォルダ含む）に右ペインを絞り込む（「すべて」で解除）。深い階層は名前を末尾省略＋全文ツールチップ、インデントを詰めて名前幅を確保する。**検索ボックスへのフォルダチップ挿入・直下トグル・ツリー⇄チップ同期・展開永続・子リスト省略等（2b）は U11**。
- **右ペイン ResultList**: フォルダ横断のフラットリスト（仮想スクロール・56px 2段組の ResultRow）。

### 2. 検索と導線（PRD 機能1）
- 起動時、検索ボックスへ即フォーカス（データ読み込みを待たない）。
- 文字入力ごとに正規化 AND 部分一致でインクリメンタル検索（**debounce 120ms**）。
- ↑↓ で結果の選択を移動、Enter またはクリックで選択中のブックマークを開く。

### 3. ファビコン表示（PRD 機能10 / docs/design）
- 各行にファビコン（16×16・radius4）。取得失敗時（`<img>` onError）は頭文字アバターへフォールバック。
- アバター色は**ホスト名ハッシュ → docs/design の9色パレット**で固定割当（同一ドメイン同色）。頭文字は白 700 9px 中央寄せ。
- ファビコン↔アバターでレイアウト不動（同一 16×16・同一 radius4 の固定枠）。

### 4. デザイン基盤（docs/design トークン / フォント）
- **デザイントークン**（accent `#4F6BED` ほか色・スペーシング・角丸・影）を Tailwind config へ定義。
- **フォント同梱**: `@fontsource/noto-sans-jp`（400/500/700）/ `@fontsource/ibm-plex-mono`（400/500）を依存追加し、必要ウエイトを import して woff2 を同梱（CDN不使用）。本文=Noto Sans JP、英数字ID/ローマ字別名=IBM Plex Mono。

### 5. ドメイン/データレイヤーとの結線
- `SearchEngine`（U6）/ `BookmarkService`（U4）/ `AliasStore`（U5）/ `Normalizer`（U3）を UI から結線。
- UI は `chrome.*` を直接呼ばず、必ずデータレイヤー経由。開く操作も `BookmarkService.openUrl` 経由。

## 受け入れ条件

> 出典: [docs/mvp-development-flow.md](../../docs/mvp-development-flow.md) U7 行・「デザイン準拠」＋ [docs/design/README.md](../../docs/design/README.md)（状態1a・固定寸法・トークン・結果行共通仕様）＋ PRD 機能1/機能10。

### 3領域シェル / レイアウト（docs/design 1a 準拠）
- [ ] ポップアップが 760×560 固定・角丸12・`overflow:hidden` で描画される。
- [ ] ヘッダー56 / 左ペイン220 / 右ペイン flex:1 の3領域で、ペイン間に区切り線（`1px solid #E7E9EE`）がある。
- [ ] SearchHeader に検索ボックス（h34・虫眼鏡・プレースホルダ）と「＋追加」ボタンが配置される（寸法・色がトークンと整合）。
- [ ] 左ペインにフォルダツリーが表示される（「すべて」+ フォルダ・インデントガイド・開閉三角）。「三角＋📁＋名前」で開閉が動作する。
- [ ] 各フォルダ行の右の選択チップ（件数表示に代替）でそのフォルダ配下（サブフォルダ含む）に右ペインが絞り込まれ、選択中が視覚的に分かる（「すべて」で解除）。
- [ ] 結果行が 56px 2段組（1段目=ファビコン+タイトル / 2段目=`padding-left:26px` のフォルダパス+別名チップ）で、別名チップは最大3個+`+N`、マッチ別名は accent 強調。
- [ ] 主要トークン（accent `#4F6BED`・背景・罫線・タイポグラフィ）が docs/design と整合する。

### 検索・導線
- [ ] 起動時、検索ボックスに 200ms 以内でフォーカス（データ読み込み完了を待たない設計）。
- [ ] 1 文字入力ごとに結果が絞り込まれる（debounce 120ms のインクリメンタル検索）。
- [ ] スペース区切りの複数キーワードが AND で機能する。
- [ ] ↑↓ で選択がハイライト移動し、Enter/クリックで選択中のブックマークが開く。
- [ ] 結果 0 件時は空状態を表示（索引読み込み中の空表示と区別する）。

### ファビコン表示
- [ ] 各行にファビコン（16×16）が表示され、取得失敗時に頭文字アバターへフォールバックする。
- [ ] 同一ドメインのアバターは常に同色（docs/design の9色パレット）。
- [ ] ファビコン↔アバターの切替でレイアウトが動かない。

### フォント / 品質 / レイヤー
- [ ] Noto Sans JP / IBM Plex Mono が woff2 同梱で適用される（CDN参照なし）。
- [ ] `pages/popup` から `chrome.bookmarks` / `chrome.storage` / `chrome.tabs` を直接呼んでいない（すべて `packages/storage` 経由）。
- [ ] ボイラープレートのデモ Popup（`injectContentScript` 等）が置換され、残っていない。
- [ ] `pnpm test` / `pnpm lint` / `pnpm type-check` がすべて通る。

## 成功指標

- **状態1aと視覚整合**: `docs/design/Findmark Popup.dc.html` の 1a と、寸法・トークン・行レイアウトが一致する。
- 起動 → 検索フォーカス 200ms 以内。
- 1,000 件規模でも 1 文字あたりの再描画が体感で引っかからない（仮想スクロールで表示行数に描画コストを固定）。

## スコープ外（後続作業単位）

- 検索ボックスへのフォルダチップ挿入・直下トグル・ツリー⇄チップ双方向同期・展開永続・多階層省略（1b/2a/2b）→ **U11**（U7は左ペインからの基本のフォルダ選択→絞り込みまで）
- モード状態機械・段階的Escape → **U8** / 別名編集（1e）→ **U9** / インライン編集・削除・アンドゥ（1d）→ **U10**
- フォルダ移動・D&D（1g）→ **U12** / 複数選択・一括バー（1f）→ **U13** / 現在ページ登録（＋追加の実機能）→ **U14**
- 検索メタ行（「〜の中から『query』— N件」）は検索状態（1b/1c/2a）の表示要素であり、当該作業単位で実装（U7の1aでは非表示）。
- `_locales`（ja/en）i18n 化 → **U18**（U7 は日本語で仮置き。ただしトークン/フォント基盤は U7 で確立）。
- **検索ランキングのデザイン準拠**（別名を最上位・空クエリ時は最近順 updatedAt降順）は #2 として据え置き。U7 は空クエリ時に U6 の既定（タイトル昇順）で表示する。
