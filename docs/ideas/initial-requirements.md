# ブックマーク検索拡張機能 初期要件定義

- **ドキュメント名**: initial-requirements
- **作成日**: 2026-07-23
- **ステータス**: MVP仕様確定 / 一部論点は継続検討

---

## 1. コンセプト

**「自分だけの別名(エイリアス)を付けて探せる」** ブックマーク検索拡張機能。

辞書や自動変換に頼らず、ユーザーが付けた別名で検索精度を上げる。別名ごと持ち運べる独自エクスポート形式を差別化の核とする。

### 設計思想

- ファイルマネージャ型(フォルダを辿る)ではなく、**Spotlight / Alfred 型の検索UI**
- フォルダ階層を辿る体験はChrome標準のブックマークマネージャが提供済みのため、そこと競合しない
- 外部通信ゼロ・host permission不要のクリーンな権限構成を維持する

---

## 2. 機能一覧(MVP)

### 2.1 検索ポップアップ(基盤)

- 拡張機能アイコンのクリック、またはキーボードショートカットで起動
- 起動時に検索ボックスへ即フォーカス
- インクリメンタル検索(入力ごとに絞り込み)
- 矢印キーで選択、Enterで開く、クリックでも開く
- 検索対象: **タイトル + フォルダ名 + 別名(aliases)**

### 2.2 検索マッチング

- スペース区切りの複数ワードAND検索、部分一致
- 結果ゼロ時のフォールバック(タイポ耐性)
- **正規化処理**(検索語・被検索文字列の両方に適用):
  - 大文字小文字を区別しない
  - `String.normalize('NFKC')` で全角・半角を統一
  - ひらがな・カタカナを同一視(コードポイント変換のみ)
- ローマ字・読みがな対応は、**ユーザーが別名として登録することで実現**する
  - 辞書同梱による肥大化を回避するための設計判断
  - 例: `gijutsu` で引きたければ、別名に `gijutsu` を登録する

### 2.3 その場で編集・整理

- 検索結果の各項目から: リネーム / URL編集 / フォルダ移動 / 削除
- **別名の追加・編集**(1件のブックマークに複数登録可)
- 削除時はアンドゥ付き(トーストで数秒間取り消し可能)
- 複数選択による一括移動・一括削除

### 2.4 現在のページをブックマーク登録

- ポップアップ内「+ 追加」ボタン
- 登録フォームでタイトル編集・保存先フォルダ選択・**別名付与**をその場で実施
- 保存先フォルダは前回使用したものを初期値に

### 2.5 インポート / エクスポート

ファイルダイアログを開くとポップアップが閉じるため、**この機能はオプションページに配置する**。

#### 標準HTML形式(Netscape Bookmark File)

- 他ブラウザ・Chrome標準機能との互換用
- インポートは新規作成のみのシンプル動作

#### 独自JSON形式(差別化の核)

別名などの独自メタデータごと持ち出せる。別アカウント・別PCへの完全移行が可能。

```json
{
  "format": "my-bookmark-search",
  "version": 1,
  "exportedAt": "2026-07-23T10:00:00+09:00",
  "bookmarks": [
    {
      "url": "https://developer.chrome.com/docs/extensions/",
      "title": "Chrome Extensions Docs",
      "folderPath": ["ブックマーク バー", "開発", "chrome"],
      "aliases": ["拡張機能", "kakuchou", "extension docs"],
      "addedAt": "2025-11-02T09:30:00+09:00"
    }
  ]
}
```

**設計意図**

| フィールド | 意図 |
|---|---|
| `url` | ブックマークIDはアカウントごとに異なるため、URLをキーとして突合する |
| `folderPath` | 配列で階層を保持。インポート時に存在しないフォルダは自動作成 |
| `aliases` | 読みがな・略称・英語名・自分だけの呼び名をすべて格納 |
| `version` | 将来フォーマットを変更しても旧ファイルを読めるようにする |

**独自JSONインポート時の重複処理**

| ケース | 動作 |
|---|---|
| 同一URLなし | 新規作成 + 別名登録(フォルダ階層は自動再現) |
| 同一URLあり・別名のみ差分 | 別名をマージ |
| 同一URLあり・タイトル/フォルダが相違 | スキップ / 上書き / 両方残す をユーザー選択(一括適用可) |

## 3. ポップアップ GUI 仕様

### 3.1 前提となる制約

| 制約 | 導かれる原則 |
|---|---|
| フォーカスを失うと即座に閉じる | 「保存ボタンで確定」型モーダルを使わず、**即時保存 + アンドゥ**で統一 |
| ファイルダイアログで閉じる | **インポート/エクスポートはポップアップに置かない**(オプションページへ分離) |
| 最大 800×600px | 左ペインは 220px 固定、残りを検索結果に割り当て |

### 3.2 全体レイアウト

```
┌────────────────────────────────────────────────────┐
│ 🔍 〔📁 開発/chrome ×〕 docs▌            [+ 追加] │ ← 固定ヘッダー
├──────────────┬─────────────────────────────────────┤
│ 📁 すべて     │ ▸ Chrome Extensions Docs           │
│  ▾ 開発      │   開発 / chrome    〔拡張機能〕〔公式〕│
│   ├ aws      │ ────────────────────────────────── │
│   └ chrome ◀ │ ▸ Manifest V3 移行ガイド            │
│  ├ 記事      │   開発 / chrome    〔mv3〕         │
│  └ 未整理    │                                     │
└──────────────┴─────────────────────────────────────┘
   フォルダツリー          検索結果(フラット)
```

- **左ペイン**: 常時表示のフォルダツリー(220px)。役割は「絞り込み指定」と「ドラッグのドロップ先」の2つ
- **右ペイン**: 検索結果。**常にフォルダ横断のフラットリスト**。各行にフォルダパスを表示
- 左で選んだフォルダの中身を右に出すファイルマネージャ型では**ない**

### 3.3 フォルダ絞り込み(チップ方式)

フォルダをクリックすると、検索ボックスの先頭にチップ `📁 開発/chrome` が挿入される。

**設計意図**: 状態を検索ボックス1箇所に集約することで、「選択中フォルダ」という隠れた状態を持たずに済む。整合性のバグが構造的に発生しない。

| 操作 | 動作 |
|---|---|
| フォルダをクリック | チップ挿入、カーソルはチップの後ろへ。既存キーワードは維持 |
| 別フォルダをクリック | チップを**置き換え**(フォルダ指定は常に1つ) |
| チップの `×` | フォルダ指定を解除。キーワードは残る |
| チップ直後で `Backspace` | 1回目で選択状態、2回目で削除 |
| キーワード手入力 | チップとの **AND条件** |
| `開発/chrome/` と手入力 | 末尾スラッシュで自動チップ化(`開発/` 時点で子フォルダをインライン補完) |

**確定事項**

- **サブフォルダは含める**(`開発` 選択で `開発/aws`・`開発/chrome` の中身も表示)。チップクリックで「直下のみ」にトグル可能
- **ツリーと双方向同期**。チップがあれば該当フォルダをハイライト + 親を自動展開
- チップは「絞り込み範囲」であり「検索語」ではない。**フォルダパスは検索語の照合対象から除外**する
- 内部的にはフォルダIDを保持するため、フォルダ名に `/` が含まれても壊れない

### 3.4 モード状態遷移

キー操作の衝突を防ぐため、明示的にモードを持たせる。

| モード | ↑↓キー | Enter | Escape |
|---|---|---|---|
| **LIST**(既定) | 選択移動 | 開く | 段階的に戻る(下記) |
| **INLINE_EDIT** | キャレット移動 | 確定 → LIST | 破棄 → LIST |
| **ALIAS_EDIT** | 候補移動 | チップ確定 | 編集終了 |
| **DRAG** | — | — | ドラッグ中止 |
| **PANEL** | 候補移動 | 決定 | パネルを閉じる |

**共通ルール**

- 編集モード中を除き、**文字を打てば検索ボックスにフォーカスが戻る**(検索ファーストの担保)
- **Escape は1段階だけ戻る**: キーワードクリア → フォルダチップ解除 → ポップアップを閉じる
- 編集中もリスト選択のハイライトを薄く保持し、どの行を編集しているか見失わないようにする

**LIST モードのキー割り当て**

| キー | 動作 |
|---|---|
| `Enter` | 現在のタブで開く |
| `Ctrl/Cmd + Enter` | 新しいタブで開く |
| `F2` / `Ctrl+E` | リネーム(INLINE_EDIT へ) |
| `Ctrl+;` | 別名編集(ALIAS_EDIT へ) |
| `Ctrl+M` | 移動(フォルダ選択パネル) |
| `Delete` | 削除(アンドゥ付き) |
| `Ctrl+D` | 現在のページを追加 |
| `Ctrl+B` | フォルダペインのトグル |

### 3.5 行の詳細デザイン

```
┌───────────────────────────────────────────────────────┐
│ ◪  Chrome Extensions Docs             [✎] [⇄] [🗑]   │
│    開発 / chrome   〔拡張機能〕〔kakuchou〕 +2         │
├───────────────────────────────────────────────────────┤
│ ◪  Manifest V3 移行ガイド                             │
│    開発 / chrome   〔mv3〕                            │
└───────────────────────────────────────────────────────┘
```

| 項目 | 仕様 |
|---|---|
| 行の高さ | **56px**(約10行が表示される) |
| 1段目 | ファビコン(16px)+ タイトル + 操作ボタン |
| 2段目 | フォルダパス + 別名チップ |
| 別名チップ | **最大3個** + `+2` で省略。`+2` クリックで全表示 |
| マッチした別名 | **必ず先頭にハイライト付きで表示**(省略対象から除外) |
| 操作ボタン | **ホバー時 または 選択時**に表示。編集 `✎` / 移動 `⇄` / 削除 `🗑` |
| タイトル省略 | 1行に収まらなければ末尾を `…` で省略、ホバーで全文をtooltip表示 |

**「なぜヒットしたか」を必ず見せる**: 英語タイトルのサイトを `kakuchou` で引いたとき、マッチした別名をハイライト付きで表示する。別名機能の価値を体感させる要となるため、省略対象から除外する。

**チェックボックスの段階表示**

| 状況 | 表示 |
|---|---|
| 通常 | 非表示(ファビコンのみ) |
| ホバー時 | **ファビコンの位置がチェックボックスに変化**(Gmail / Finder と同じ挙動) |
| 1件以上選択中 | 全行で常時表示 + ヘッダーが「**3件選択中** [移動] [削除] [選択解除]」バーに切り替わる |

常時表示にすると業務システム風になるため、段階的に出す。

### 3.6 ファビコン表示

**方式: `favicon` 権限 + 頭文字アバターのフォールバック**

```
favicon権限で取得
  ↓ 取得失敗 / 未訪問サイト
頭文字アバターにフォールバック
```

```json
// manifest.json
"permissions": ["bookmarks", "storage", "activeTab", "favicon"],
"web_accessible_resources": [{
  "resources": ["_favicon/*"],
  "matches": ["<all_urls>"]
}]
```

```js
const faviconUrl = (pageUrl, size = 32) =>
  `chrome-extension://${chrome.runtime.id}/_favicon/?pageUrl=${encodeURIComponent(pageUrl)}&size=${size}`;
```

**頭文字アバターの仕様**

- 表示文字: ドメイン名の先頭1文字を大文字化(`developer.chrome.com` → `D`)。`www.` などのサブドメインは除去してから判定
- 背景色: ドメイン文字列のハッシュから固定パレット(8〜12色)を選択。**同じドメインは常に同じ色**になり、色自体が識別の手がかりになる
- サイズ・角丸はファビコンと揃え、**切り替わってもレイアウトが動かない**ようにする
- 判定方法: `<img>` の `onerror`、またはデフォルトアイコン(地球儀)が返ってきた場合の検出。後者は実測して挙動を確認する

**方式選定の経緯**

| 方式 | 判定 | 理由 |
|---|---|---|
| A. `favicon` 権限 | **採用** | 通信ゼロ、Chrome側がキャッシュを持つため実装が軽い |
| B. Google ファビコンAPI | 不採用 | 外部通信が発生し、キャッシュ層・設定トグル・ポリシー追記が必要になる |
| C. 頭文字アバターのみ | フォールバックとして採用 | 未訪問サイト(特にインポート直後)の見た目破綻を防ぐ |

A案単体では、未訪問サイトのファビコンをChromeが持っていないため、独自JSONのインポート直後にアイコンが空になる問題がある。頭文字アバターを組み合わせることでこれを解消する。

**注意**: `favicon` 権限は低リスク権限として扱われ、インストール時に目立つ警告は出ないはずだが、申請前に現行ドキュメントで確認すること。

### 3.7 ドラッグ&ドロップ(フォルダ移動)

**開始**

- 行全体をドラッグ可能(専用ハンドルは置かず、発見しやすさを優先)
- **5px以上の移動で開始**(クリックとの誤判定防止)
- ドラッグ中はゴースト表示(タイトル + 件数バッジ)
- 複数選択時は**選択済みの全件をまとめて運ぶ**

**ドロップ先**

- **フォルダのみ**。「フォルダに入れる」操作だけをサポート
- **フォルダ内の並び順変更はMVP対象外**(フラットな検索結果では並び順の概念が成立しないため)
- 現在の親フォルダはグレーアウトして無効化

**ドラッグ中の挙動**

| 挙動 | 仕様 |
|---|---|
| スプリングロード展開 | 閉じたフォルダに **600ms** ホバーで自動展開 |
| オートスクロール | ペイン上下端 **40px** で自動スクロール |
| ドロップ可能表示 | 対象フォルダを枠線 + 背景色でハイライト |
| 中止 | `Escape` またはペイン外でドロップ |

**ドロップ後**

- `chrome.bookmarks.move` を即時実行
- トースト表示: 「"◯◯" を 開発/chrome へ移動しました **[元に戻す]**」/ 5秒間有効
- **移動しても検索結果から消さない**。フォルダパス表示だけ更新する(消えると「どこへ行ったか分からない」不安が出るため)

**キーボード代替(必須)**

`Ctrl+M` → フォルダ選択パネル → フォルダ名を打って絞り込み → `Enter` で移動。慣れたユーザーにはドラッグより速いため、ドラッグより先に実装してもよい。

### 3.8 複数選択

| 操作 | 動作 |
|---|---|
| `Ctrl/Cmd + クリック` | 個別に選択を追加 |
| `Shift + クリック` | 範囲選択 |
| `Ctrl/Cmd + A` | 全件選択 |

- ドラッグ時は選択済み全件をまとめて移動。ゴーストに件数バッジを表示
- アンドゥは**一括操作を1単位**として扱う(20件移動なら1回で全部戻る)
- 選択中はヘッダーが一括操作バーに切り替わる(3.5節参照)

> 詳細仕様は継続検討(第6章 未確定論点を参照)

### 3.9 リネーム / URL変更

```
▸ [Chrome Extensions Docs              ]  ← タイトル
  [https://developer.chrome.com/docs/...]  ← URL
  開発 / chrome
```

- **インライン編集**(モーダルなし)。行がその場で2フィールドに展開
- **タイトルとURLを同時表示**(片方ずつ開くと往復が発生するため)
- `Tab` でタイトル → URL → 別名へ移動
- `Enter` で両方まとめて確定、`Escape` で両方破棄
- **フォーカスアウト時は「確定」**(ポップアップが閉じる事故で入力が消えるのを防ぐ。破棄はEscapeの明示操作でのみ)
- URL不正時は赤枠 + 確定不可、エラーは行の下にインライン表示
- タイトル空欄は不可(空ならURLを代用)

### 3.10 別名(エイリアス)編集

```
別名: 〔拡張機能 ×〕〔kakuchou ×〕〔公式 ×〕 [入力中...]
```

| 操作 | 動作 |
|---|---|
| 入力 → `Enter` / `,` / `Space` | チップとして確定 |
| `Backspace`(入力欄が空) | 直前のチップを削除 |
| チップの `×` | 削除 |
| チップをクリック | 再編集(テキストに戻る) |
| `Escape` | 編集終了(入力途中の文字は破棄) |

**バリデーション**

- 正規化(NFKC・小文字化・カナ統一)後に比較して**重複を自動で弾く**。弾いた際は既存チップを一瞬光らせて気づかせる
- 空白のみは無視
- **1件あたり最大20個、1個あたり最大50文字**

### 3.11 現在のページの登録

| 状態 | ヘッダー右の表示 | クリック時 |
|---|---|---|
| 未登録 | `+ 追加` | **即座に登録** → 編集パネルを開く |
| 登録済み | `★ 登録済み` | 該当ブックマークの編集パネルを開く |

```
┌─ 追加しました ──────────────────────┐
│ 名前   [Chrome Extensions Docs    ] │
│ フォルダ [開発 / chrome         ▾] │ ← 前回使用フォルダが初期値
│ 別名   〔          ×〕[入力...]     │
│                    [削除]  [完了]   │
└─────────────────────────────────────┘
```

- **「即座に登録してから編集」**(Chrome標準と同じ挙動)。パネル操作中にポップアップが閉じても登録は残る
- フォルダ選択はドロップダウン + 絞り込み検索(階層が深くても打って選べる)
- `[削除]` は「やっぱり登録しない」の受け皿、`[完了]` はパネルを閉じるだけ
- 各フィールドは変更のたびに即時保存

## 4. データ設計

### 4.1 別名データ

| 項目 | 仕様 |
|---|---|
| 保存先 | `chrome.storage.sync`(別PC自動同期) |
| 紐付けキー | **ブックマークIDではなくURLのハッシュ** |
| 格納方式 | **100件ずつのチャンクを1キー**にまとめる(`alias_chunk_0`, `alias_chunk_1`...) |
| 容量超過時 | `storage.local` にフォールバック |

**設計理由**

- ブックマークIDは端末・アカウントをまたぐと変わるため、IDで紐付けると同期・インポート時に別名がすべて外れる
- `chrome.storage.sync` には「1アイテム8KB / 最大512アイテム」の制限がある。ブックマーク1件=1キーにすると512件で破綻するため、チャンク分割が必須

### 4.2 削除データ(ゴミ箱)

即時アンドゥとは別に、2層構造で保持する。

| 層 | 保持期間 | 置き場所 |
|---|---|---|
| 即時アンドゥ(トースト) | 5秒 | メモリ |
| **ゴミ箱** | 30日(設定可) | `storage.local` |

- **保存対象**: URL・タイトル・元のフォルダパス・別名・削除日時
- **フォルダを削除した場合は配下のツリーごと丸ごと保存**する
- **復元先**: 元のフォルダパスへ戻す。フォルダが存在しなければ**自動で再作成**
- **上限**: 件数上限(例: 500件)または容量上限を設け、超過分は古いものから自動削除
- **UI**: オプションページに「ゴミ箱」タブを設置。ポップアップ側は即時アンドゥのみ

**実装メモ**: `chrome.bookmarks.remove` に復元APIはないため、削除前データを保持して**再作成で復元**する。ID・作成日時は変わる点に注意。

### 4.3 フォルダツリーの折りたたみ状態

| 項目 | 仕様 |
|---|---|
| 保存先 | **`storage.local`**(`sync` は不可) |
| 保存内容 | 展開中のフォルダIDの配列 |
| 初期状態 | ブックマークバー直下のみ展開、他は折りたたみ |

- `sync` に入れると別PCで無意味なIDを参照して壊れるため、必ず `local` に置く
- **チップ選択による自動展開は一時的なものとして扱い、保持しない**(自動展開が蓄積して全部開いた状態になるのを防ぐ)
- 存在しなくなったIDは起動時に掃除する

### 4.4 その他の保存項目

| 項目 | 保存先 |
|---|---|
| 前回使用したフォルダ(登録時の初期値) | `storage.local` |
| ユーザー設定(ゴミ箱保持期間など) | `storage.sync` |

## 5. 技術仕様

| 項目 | 内容 |
|---|---|
