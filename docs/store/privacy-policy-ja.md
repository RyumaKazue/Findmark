# Findmark プライバシーポリシー

- **対象**: Chrome 拡張機能「Findmark」（バージョン 1.0.0 以降）
- **最終更新日**: 2026-08-14

## 要約

**Findmark はいかなるデータも収集・送信しません。** ブックマーク、別名（エイリアス）、検索語、設定はすべてお使いのブラウザ内にとどまります。開発者を含む第三者がこれらを閲覧することはできません。

## 収集する情報

**ありません。** Findmark は次のいずれも行いません。

- 個人を識別できる情報（氏名・メールアドレス・住所等）の収集
- 閲覧履歴・訪問したページの内容の収集
- 検索語・別名・ブックマークの外部への送信
- 利用状況の計測（テレメトリ・アナリティクス）、クラッシュレポートの送信
- 広告の配信、広告目的のトラッキング
- Cookie や類似技術によるユーザー識別

## 拡張機能が扱う情報と保存先

Findmark は機能を提供するために、次の情報を**お使いのブラウザ内でのみ**扱います。

| 情報 | 用途 | 保存先 |
|---|---|---|
| Chrome のブックマーク（タイトル・URL・フォルダ構成） | 検索と整理（リネーム・移動・削除・追加） | Chrome のブックマーク（Findmark は独自の複製を保存しません） |
| 別名（エイリアス） | 自分の呼び名でブックマークを引くため | `chrome.storage.sync`（容量上限を超えた場合は `chrome.storage.local`） |
| 設定（表示言語、ゴミ箱の保持日数） | 拡張機能の動作設定 | `chrome.storage.sync` |
| ゴミ箱（削除したブックマークとその別名） | 削除の取り消し（既定30日） | `chrome.storage.local` |
| ポップアップの表示状態（フォーカス位置・フォルダ・選択行・検索語） | 次回起動時に作業状態を復元するため | `chrome.storage.local` |
| 現在のタブのタイトルと URL | ［＋追加］を押したときにブックマークとして登録するため | 一時的に扱うのみ（保存はブックマークとして） |

`chrome.storage.sync` に保存された情報は、Chrome の同期機能が有効な場合、**Google の同期の仕組みを通じて同じアカウントの端末間で共有されます**。これは Chrome ブラウザの標準機能によるもので、Findmark が独自のサーバーへ送信するものではありません。

## 外部への通信

Findmark は**外部サーバーとの通信を一切行いません**。`fetch` / `XMLHttpRequest` / WebSocket による外部リクエストを含まず、ホスト権限（特定サイトへのアクセス権）も要求しません。表示に使うフォントとアイコンはすべて拡張機能に同梱しており、CDN 等の外部からは読み込みません。

ファビコン（サイトのアイコン）は Chrome がローカルに保持しているものを `favicon` 権限で参照するだけで、Findmark がサイトへ接続することはありません。

## 権限を要求する理由

| 権限 | 理由 |
|---|---|
| `bookmarks` | ブックマークの検索と、リネーム・URL編集・移動・削除・追加・復元を行うため |
| `storage` | 別名・設定・ゴミ箱・表示状態をブラウザ内に保存するため |
| `activeTab` | ［＋追加］を押したときに、現在のタブのタイトルと URL を取得するため |
| `favicon` | 検索結果に各サイトのアイコンを表示するため |

## 第三者への提供

収集するデータが存在しないため、**第三者への提供・販売・共有は一切ありません**。

## データの削除

Findmark が保存した別名・設定・ゴミ箱は、Chrome から拡張機能をアンインストールすると削除されます。ゴミ箱の内容はオプションページの「ゴミ箱」タブからいつでも個別に削除できます。ブックマーク自体は Chrome が管理するデータであり、拡張機能の削除では消えません。

## 子どものプライバシー

Findmark は年齢を問わず利用でき、いかなる利用者からも情報を収集しません。

## 本ポリシーの変更

内容を変更した場合は、本ページの「最終更新日」を更新し、変更後のバージョンを Chrome Web Store の掲載情報から参照できるようにします。
