## 拡張機能名

```
Findmark
```

> manifest の `name` は `__MSG_extensionName__`（`_locales/ja/messages.json`）から解決される。

## 概要（短い説明・132文字以内）

```
別名(エイリアス)を付けて探せるブックマーク検索。辞書に頼らず自分だけの呼び名で素早く見つかる。外部通信ゼロで安心。
```

> manifest の `description`（`_locales/ja/messages.json` の `extensionDescription`）と同一。**変更する場合は両方を同時に直す。**

## 詳細な説明

```
Findmark は「あのページ、なんて名前だったっけ？」をなくすブックマーク検索です。

ブックマークに自分だけの別名（エイリアス）を付けておけば、正式なタイトルを思い出せなくても、いつもの呼び名で数秒で引き出せます。「請求書のひな形」を "せいきゅう" や "invoice" で、社内Wikiを "wiki" で。呼び名は何個でも登録できます。

■ 主な機能
・別名で引ける検索: 1文字入力するごとに絞り込み。全角/半角・大文字小文字・ひらがな/カタカナの違いを吸収します
・キーボードだけで完結: 検索ボックス・フォルダ・結果リストを ←→↑↓ で移動し、Enter で開く
・フォルダで絞り込み: 左のフォルダを選ぶと、そのフォルダの直下だけを対象に検索
・その場で整理: 検索結果の行で、名前の変更・URLの修正・削除・フォルダ移動ができます
・まとめて操作: 複数選択して一括で移動・削除
・現在のページを登録: ヘッダーの［＋追加］で今開いているページをその場でブックマーク＋別名付け
・取り消せる削除: 削除直後の5秒アンドゥに加え、30日間はゴミ箱から復元できます
・引っ越しできる: 別名を含む独自JSON、または一般的なHTML形式でインポート/エクスポート

■ プライバシー
・外部サーバーへの通信は一切ありません。検索・別名・設定はすべてお使いのブラウザ内で完結します
・閲覧履歴の収集、利用状況の送信、広告・解析は一切行いません
・別名と設定は Chrome の同期ストレージに保存されるため、同じ Google アカウントでサインインした端末間で共有されます

■ 権限について
・ブックマークの読み取りと変更: 検索対象の取得と、名前の変更・移動・削除・追加のために必要です
・サイトのアイコンの読み取り: 検索結果に各サイトのファビコンを表示するために必要です（favicon 権限。ページの内容や閲覧履歴にはアクセスしません）
・ストレージ: 別名・設定・ゴミ箱をブラウザ内に保存するために使います
・現在のタブ（activeTab）: ［＋追加］を押したときに、今開いているページのタイトルとURLを取得するために使います

■ 起動ショートカットについて
既定のショートカットは Ctrl+Shift+F（Mac は Command+Shift+F）です。他の拡張機能が同じキーを先に使っている場合、インストール時に**未割り当てのまま**になることがあります。その場合はオプションページの「設定」タブに案内が表示されるので、chrome://extensions/shortcuts を開いて任意のキーを割り当ててください。

■ 対応環境
Chrome（Manifest V3）。日本語 / 英語に対応しています。
```

## 単一用途の説明（Single purpose）

```
ユーザーが自分で付けた別名（エイリアス）でブックマークを検索し、その場で整理できるようにすること。
```

## 権限の理由（Permission justification）

ダッシュボードの「プライバシーへの取り組み」タブに入力する。manifest の `permissions`（4つ）と1対1で対応する。

| 権限 | インストール時の警告 | 入力する理由 |
|---|---|---|
| `bookmarks` | 「ブックマークの読み取りと変更」 | ブックマークの検索対象を取得し、リネーム・URL編集・移動・削除・新規追加・復元を行うために必要です。 |
| `storage` | なし | ユーザーが登録した別名、表示言語・ゴミ箱の保持日数などの設定、削除データ（ゴミ箱）、ポップアップの表示状態をブラウザ内に保存するために必要です。 |
| `activeTab` | なし | ［＋追加］を押した時点で、現在開いているタブのタイトルとURLを取得してブックマークとして登録するために必要です。ページの内容は読み取りません。 |
| `favicon` | 「アクセスしたウェブサイトのアイコンの読み取り」 | 検索結果の各行に、対象サイトのファビコンを表示するために必要です。Chrome がローカルに保持しているアイコンを参照するだけで、外部への通信は行いません。 |

- **ホスト権限**: 要求しません（`content_scripts` / `host_permissions` なし）。
- **リモートコード**: 使用しません（すべてのスクリプトとフォントを拡張機能に同梱）。
