# ストア用スクリーンショット 撮影手順

- **ドキュメント名**: store/screenshots
- **対象**: Chrome Web Store の「ストアの掲載情報 > スクリーンショット」
- **担当**: リリース実務（**人手で撮影する**。拡張機能を実際に読み込んだ画面が必要なため、自動生成しない）

## 要件（Chrome Web Store）

| 項目 | 値 |
|---|---|
| サイズ | **1280×800**（または 640×400。1280×800 で統一する） |
| 形式 | PNG（24bit・アルファなし推奨） |
| 枚数 | **5枚**（最低1枚。ストアの推奨は最大5枚） |
| 余白 | 画面全体を埋める。ポップアップ（760×560）は中央に配置し、余白は背景色で埋める |
| 文字 | 画像内の説明文は入れない（言語別素材の管理コストを避ける。掲載言語は ja / en の2つ） |

> ポップアップ実寸は 760×560 のため、1280×800 のキャンバス中央に配置すると上下左右に余白ができる。
> 背景は `#F7F8FA`（design トークンの `pane`）で塗り、拡張の見た目と調和させる。

## 事前準備

1. `pnpm build` を実行し、`dist/` を `chrome://extensions`（デベロッパーモード）から「パッケージ化されていない拡張機能を読み込む」で読み込む。
2. **撮影用のブックマークを用意する**（実データの流出を防ぐため、専用プロファイルまたは新規プロファイルを使う）。
   - フォルダ: `開発`（配下に `chrome`, `記事`）／ `仕事`（配下に `請求`）／ `あとで読む`
   - ブックマーク: 各フォルダに3〜6件。タイトルは実在サービス名（GitHub / MDN / Figma 等）で、URL も実在のものにする
   - 別名: 代表的な数件に付ける（例: GitHub → `ghub` `ぎっと` / MDN → `mdn` `りふぁ` / 請求書テンプレ → `せいきゅう` `invoice`）
3. 表示言語は **日本語（既定）** で撮影する。英語版の掲載にも同じ画像を使う（画像内に文言を焼き込まないため）。
4. ズームは 100%、OS のダークモードはオフ、通知バナー等が写り込まないようにする。

## 撮影シナリオ（5枚）

| # | 状態 | 操作手順 | 見せたいこと |
|---|------|---------|------------|
| 1 | 通常（design 1a） | ポップアップを開いた直後（検索前・スコープは「すべて」） | 3領域レイアウトと一覧性。**最初の1枚＝ストアのサムネイル**になるため最も丁寧に整える |
| 2 | 別名ヒット（design 1c） | 検索ボックスに `せいきゅう` と入力 | 別名（accent 塗りチップ）で目的の1件に到達できること＝本拡張の中核価値 |
| 3 | インライン編集（design 1d） | 結果行にホバー →［✎］（または F2） | 検索結果の場でリネーム/URL編集が完結すること |
| 4 | 複数選択と一括操作（design 1f） | 行を Ctrl/Cmd+クリックで3件選択 | 一括操作バー（N件選択中 /［移動］［削除］） |
| 5 | フォルダスコープ（design 1b/2a） | 左ペインで `開発 > chrome` を選択 | フォルダ直下に絞り込む動きと、検索ボックスのスコープチップ |

> 状態番号は [docs/design/README.md](../design/README.md) の状態定義に対応する。

## 撮影方法（macOS の例）

1. ポップアップを開いた状態で `Shift+Command+4` → `Space` でウィンドウ単位のキャプチャ（影なしにする場合は `Option` を併用）。
2. 取得した PNG を 1280×800 のキャンバス中央に配置する（`sips` などで背景合成するか、画像編集ツールを使う）。
3. ファイル名は `screenshot-1-overview.png` … `screenshot-5-folder-scope.png` の形式にし、`docs/store/assets/`（Git 管理外にする場合は提出用フォルダ）へ保存する。

> ポップアップはフォーカスを外すと閉じるため、`chrome-extension://<拡張ID>/popup/index.html` を通常タブで開いて撮影してもよい。
> その場合はウィンドウ幅を広めに取り、余分な余白が写らないようポップアップ領域だけを切り出す。
